# Support

- Read the [wiki](https://github.com/TerkWerX/STUDIO-INVENTORY/wiki) for installation, mobile access, backup, and troubleshooting.
- Ask usage questions in [Discussions](https://github.com/TerkWerX/STUDIO-INVENTORY/discussions).
- Report reproducible bugs through the [issue tracker](https://github.com/TerkWerX/STUDIO-INVENTORY/issues).
- Report security concerns through the [security policy](SECURITY.md).

When requesting help, include the Studio Inventory version, operating system, browser, what you expected, what happened, and the exact error text. Remove serial numbers, license keys, receipts, owner PINs, and private network details first.
